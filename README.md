# 捡雷人

> 别人渡劫要命，他渡劫要饭——直到第九道雷劈开他的丹田，掉出个老祖。

**题材**：仙侠 · 黑色幽默 · 职场寓言　**作者**：灯下人　**4 章 · 11,619 字**

杂役赵拾是修仙界最底层的灵根破碎者，却意外发现破碎丹田能像储物袋一样吸收别人渡劫时逸散的雷劫余烬。他专挑各派天才渡劫时蹲点捡雷，目标是三年内攒够九道天雷把自己劈成散仙。可当他引下第九道天雷，雷劫劈开丹田储物空间，掉出三百年前失踪的渡劫期老祖——老祖一直躲在他丹田里靠他捡的雷续命。老祖替他扛下天雷，他却因“窝藏”之功被仙界判去守雷池，成了编制内雷劫管理员。
